Configure and run the app.

Install, configure privately and inspect the nine experiments.

01

Prerequisites

Use Node.js 24+, API credit and a supported model. Windows may require Git Bash. The app starts a loopback OTLP HTTP/JSON receiver on a free port per run; no Docker or hosted observability account is needed.

node --version
npm --version
02

Install and configure

Preserve an existing .env, or copy the template. Enter your model API key privately. The local receiver uses generated authentication; no collector token is required in .env.

cd .\agent-sdk\lesson47-opentelemetry
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
03

Start and navigate

Keep the terminal open. Visit all five pages. Use the experiment selector, native trace tree, metric points, event filter, diagnostics and downloadable evidence.

npm start
# http://127.0.0.1:3147
04

Compare the three signals

Run All, Metrics, Logs and Traces separately. The UI displays exactly what arrived. Metrics may export several delta batches: rows are points, not unique metric names or a session total.

npm run sample:env -- all
npm run sample:env -- metrics
npm run sample:env -- logs
npm run sample:env -- traces
05

Link and attribute

Linked creates an actual active host span and exports it through the official OTLP exporter. Tags attaches the fictional student 47 identity. Filter the event table by that exact value.

npm run sample:env -- linked
npm run sample:env -- tags
06

Inspect content and failure

Content opts in only for disposable fictional notes. Off disables CLI export. Rejected endpoint returns a real HTTP 503: compare successful SDK completion with receiver rejection records and stderr diagnostics.

npm run sample:env -- content
npm run sample:env -- off
npm run sample:env -- unreachable
npm test

Your private .env

ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3147
# Windows only, if needed:
# CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe

Keep the key private, restart after edits, and preserve an existing file. Existing shell values take precedence. If the port is occupied, change PORT.
