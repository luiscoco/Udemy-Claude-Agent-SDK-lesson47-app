01

Classroom receiver versus production collector

The included receiver accepts actual OTLP HTTP/JSON exports into memory and closes after each run. It does not provide durable storage, retries, a production collector pipeline or a hosted tracing service. Use an OpenTelemetry Collector and your chosen backend for production.

02

Traces are beta

The pinned runtime currently emits interaction, llm_request and tool spans. Span names and attributes may change. Native hook spans require additional detailed beta tracing settings and an endpoint override; the normal PreToolUse callback is not presented as a hook span.

03

The response channel stays separate

Do not use the console exporter through the SDK, because it writes into the SDK message channel. This sample receives native telemetry over a separate HTTP endpoint.

04

Trace context is actual

Linked mode uses a registered NodeTracerProvider, an active span and the official HTTP trace exporter. No trace IDs or parent IDs are fabricated. Only this experiment creates a host span; the other trace experiments show CLI roots.

05

Metrics are points, not a bill

The table shows raw native metric points, attributes and aggregation temporality. Repeated exports are not automatically summed. Native cost metrics are estimates, not an invoice. The app does not query organization billing.

06

Privacy and opt-in content

Only a fictional disposable note is available to Read. Content logging is off by default and enabled only in the labelled Content experiment. Even structural telemetry can carry session or user identifiers. The classroom receiver redacts account user/organization attributes and the current API credential before UI storage. This is not a comprehensive production DLP solution.

07

Diagnose failure

Rejected endpoint uses a live authenticated receiver path returning HTTP 503. It records rejections, accepts no telemetry for that path, and captures exporter diagnostics through the SDK stderr option. This is a deliberate HTTP rejection rather than an invented network outage.

08

Short-lived exporters

One-second metrics, log and trace intervals help exports arrive while the task is running. Clean process shutdown tries to flush but cannot guarantee delivery, and killed processes can lose buffered data.

09

Per-user filtering

Tags uses enduser.id=student%2047 and tenant.id=demo-school. The native resource contains the decoded value student 47. These are synthetic teaching identities, not the API account owner.
