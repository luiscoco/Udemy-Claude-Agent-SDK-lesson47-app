Application labWhat you will learnHow to runArchitecture & workflowCode walkthrough
01

Follow the actual export path

The Agent SDK launches an instrumented CLI. Response messages return through the SDK pipe; OTLP data travels separately to the receiver.

02

Select three independent signals

Enable telemetry, then choose metrics, log events and beta traces independently. Compare all signals with metrics-only, logs-only and traces-only experiments.

03

Read a native trace tree

Inspect interaction, model-request and Read-tool spans, their durations, parent IDs and trace IDs. The diagram labels host code separately from CLI instrumentation.

04

Link an application span

Run query() inside a real active OpenTelemetry host span. Verify the CLI interaction shares its trace ID and references its span ID.

05

Tag and filter classroom activity

Set service.name and encoded resource attributes. Filter actual tool-result events by the fictional enduser.id, without exposing account identity.

06

Verify delivery and control content

Compare default telemetry with explicit synthetic prompt/tool-content logging. Observe a deliberately rejected endpoint and an agent that still finishes. Short export intervals help short calls but cannot guarantee delivery.
